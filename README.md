# Season 26/27 — Training Plan

Full-screen Android app (PWA) for Tomas's Season 26/27 plan: Mažeikiai 10K, Kaunas & Riga halves,
Trakai sprint triathlon, Tallinn marathon. Data lives in a private Google Sheet behind an Apps Script
API; the app connects with a personal key from the install link (never stored in this repo).

Install on Android: open the personal link in Chrome → ⋮ → **Install app**.
